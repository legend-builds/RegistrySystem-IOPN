# Builder Registry Smart Contract

A robust Solidity smart contract and TypeScript Hardhat project designed for tracking builder profiles, metrics, and score claims within Web3 ecosystems.

## Deployed Contract Information
* **Network:** IOPn Testnet
* **Contract Address:** `0x300e6B34d2fdBcc390f63fbAf2142AB173Aa3CA1`

## Features
- **Builder Registration:** Allows developers to register their profile linked with their GitHub username and wallet..
- **Initial Reward:** Automatically grants starting points upon successful registration.
- **Access Control:** Owner-restricted functions for managing points and network metrics.

## Tech Stack
- **Solidity** (^0.8.20)
- **Hardhat**
- **TypeScript**
- **Ethers.js**

## Getting Started

### Prerequisites
Make sure you have Node.js and npm installed.
